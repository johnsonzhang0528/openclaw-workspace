# 智慧快捷指令系統

## 技能信息
- **名稱**：smart-shortcuts
- **版本**：1.0.0
- **作者**：OpenClaw Team
- **描述**：智慧快捷指令 - 自定義快捷指令系統
- **分類**：productivity

## 功能特性
- 🎯 **自定義指令**：創建個人化的快捷指令
- 🎨 **模板系統**：使用預定義模板快速創建
- 🔍 **上下文感知**：根據對話上下文智能建議
- 🔄 **指令鏈**：創建多步驟的指令序列
- 📤 **分享導入**：分享和導入指令配置
- 📊 **使用統計**：追蹤指令使用頻率
- 🤖 **AI 增強**：AI 輔助創建和優化指令

## 安裝要求
- OpenClaw 版本：2026.2.0 或更高
- Python 版本：3.8+

## 使用方式
```
/快捷指令 - 打開快捷指令管理
/shortcut - 快捷命令
!<指令名> - 執行快捷指令
```

## 命令列表
- `/快捷指令` - 顯示指令管理選單
- `/快捷指令 新增` - 創建新指令
- `/快捷指令 列表` - 查看所有指令
- `/快捷指令 編輯 <名稱>` - 編輯指令
- `/快捷指令 執行 <名稱>` - 執行指令
- `/快捷指令 模板` - 使用模板創建
- `/快捷指令 分享` - 分享指令配置

## 指令類型
1. **文字指令**：發送預定義文字
2. **命令指令**：執行系統命令
3. **組合指令**：多個指令的組合
4. **條件指令**：根據條件執行不同操作
5. **互動指令**：需要使用者輸入的指令

## 配置選項
```json
{
  "skills": {
    "smart-shortcuts": {
      "enabled": true,
      "config": {
        "max_shortcuts": 100,
        "allow_system_commands": false,
        "context_awareness": true,
        "ai_assistance": true,
        "backup_interval": 3600,
        "default_prefix": "!"
      }
    }
  }
}
```

## 安全限制
- 可配置系統命令執行權限
- 指令執行前確認（可選）
- 指令使用日誌記錄
- 惡意指令檢測和阻止
