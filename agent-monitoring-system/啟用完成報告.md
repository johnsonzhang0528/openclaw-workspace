## 🚨 已知問題與解決方案

### 問題 1: OpenClaw Gateway 連接失敗
- **現象**: `Connection refused` 錯誤
- **原因**: OpenClaw Gateway 服務未運行
- **影響**: 會話同步功能受限
- **解決方案**: 啟動 Gateway 服務
  ```bash
  openclaw gateway start
  ```

### 問題 2: 方法簽名不匹配
- **現象**: `unexpected keyword argument 'limit'` 錯誤
- **影響**: 會話追蹤和資源監控的部分功能
- **解決方案**: 需要統一方法接口簽名
- **緊急程度**: 低 (不影響核心監控功能)

### 問題 3: 屬性訪問錯誤
- **現象**: `'NoneType' object has no attribute 'cpu_percent'`
- **影響**: 資源監控數據獲取
- **解決方案**: 修復資源監控器初始化邏輯
- **緊急程度**: 中 (影響監控數據完整性)
