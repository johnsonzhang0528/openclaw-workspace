# 效能監控儀表板

## 技能信息
- **名稱**：performance-monitor
- **版本**：1.0.0
- **作者**：OpenClaw Team
- **描述**：效能監控儀表板 - 監控系統資源使用情況
- **分類**：monitoring

## 功能特性
- 📊 **即時監控**：CPU、記憶體、磁碟、網路使用率
- 📈 **歷史圖表**：資源使用趨勢圖
- ⚠️ **智能警報**：自定義警報規則和通知
- 🔍 **程序分析**：查看和分析運行中的程序
- 📋 **效能報告**：生成詳細的效能報告
- 🔄 **自動優化**：建議系統優化方案
- 📱 **行動儀表板**：Telegram 友好的介面

## 安裝要求
- OpenClaw 版本：2026.2.0 或更高
- Python 版本：3.8+
- psutil 套件：系統監控庫

## 使用方式
```
/效能監控 - 打開效能監控儀表板
/perf - 快捷命令
```

## 命令列表
- `/效能監控` - 顯示即時狀態
- `/效能監控 圖表 [類型]` - 查看歷史圖表
- `/效能監控 警報` - 管理警報設定
- `/效能監控 程序` - 查看運行中的程序
- `/效能監控 報告` - 生成效能報告
- `/效能監控 設定` - 配置監控選項

## 監控指標
- **CPU**：使用率、核心數、溫度
- **記憶體**：總量、使用量、交換空間
- **磁碟**：使用率、IOPS、讀寫速度
- **網路**：頻寬、連線數、延遲
- **系統**：負載、運行時間、程序數

## 配置選項
```json
{
  "skills": {
    "performance-monitor": {
      "enabled": true,
      "config": {
        "update_interval": 5,
        "history_duration": 86400,
        "alert_rules": {
          "cpu_threshold": 80,
          "memory_threshold": 85,
          "disk_threshold": 90
        },
        "notifications_enabled": true,
        "chart_theme": "dark"
      }
    }
  }
}
```

## 安全考慮
- 只讀取系統資訊，不修改系統設定
- 資料本地儲存，不外傳
- 可配置的監控頻率
- 資源使用限制
